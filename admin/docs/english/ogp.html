Geeklog OGP plugin

Purpose

OGP centralizes social metadata for Geeklog pages. It outputs Open Graph and Twitter/X card metadata for Geeklog pages, and compatible content plugins may register richer page-level image or video metadata.

Configuration

Default social image

Set the public URL of the image OGP should use when the current page does not provide a more specific image.

Interoperability

Content plugins may call OGP_registerSocialMetadata() before the Geeklog document header is rendered. OGP then uses the registered title, description, canonical URL, image and optional video metadata.

When no provider registers metadata, OGP keeps its backward-compatible Geeklog page detection and generates Open Graph and Twitter/X card metadata.

Removed legacy features in OGP 2.0

The obsolete external Facebook Like and Facebook Comments widgets, their SDK, autotags and configuration options have been removed. Sharing buttons belong to the site theme or another dedicated sharing component; OGP focuses only on social metadata.
