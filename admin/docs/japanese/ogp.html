Geeklog OGP プラグイン

目的

OGP は Geeklog ページのソーシャルメタデータを一元管理します。 Open Graph と Twitter/X Card のメタデータを出力し、互換性のある コンテンツプラグインはページ固有の画像や動画など、より詳細な メタデータを登録できます。

設定

デフォルトのソーシャル画像

現在のページに適切な画像がない場合に OGP が使用する公開画像 URL を設定します。

相互運用性

コンテンツプラグインは、Geeklog が最終的なドキュメントヘッダーを 生成する前に OGP_registerSocialMetadata() を呼び出して、 タイトル、説明、canonical URL、画像、動画などのページ固有メタデータを 登録できます。

プロバイダーがメタデータを登録しない場合、OGP は従来互換の Geeklog ページ検出を使用して Open Graph と Twitter/X Card の メタデータを生成します。

OGP 2.0 で削除された旧機能

旧 Facebook Like、Facebook Comments、Facebook SDK、関連する autotag と設定項目は削除されました。共有ボタンはテーマまたは 専用コンポーネントの役割とし、OGP はソーシャルメタデータの生成に 専念します。
